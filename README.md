## ✨ ماذا تجد في كل مقرر؟

- 📝 **ملخصات منظمة** لكل باب وفصل
- 🗺️ **خرائط ذهنية** تجمع الكتاب في صورة واحدة
- 🃏 **بطاقات** لحفظ التعريفات والمصطلحات
- ✅ **اختبارات** واختبار محاكي بمؤقت قبل الامتحان
- 🌙 **وضع ليلي** وتكبير الخط

## 👤 حفظ التقدّم

- 📝 عند أول دخول لصفحة المقرر يُطلب منك ملء **نموذج تسجيل قصير** (الاسم والرقم الجامعي والبريد) مرة واحدة فقط.
- 💾 يُحفظ تقدّمك تلقائياً على جهازك.
- ☁️ وإن أردت أن تجد تقدّمك على الجوال والحاسوب معاً، **سجّل الدخول بحساب Google أو بالبريد الإلكتروني** من داخل صفحة المقرر: تُحفظ المطالب التي أنهيتها، والبطاقات التي أتقنتها، ونتائج اختباراتك.
